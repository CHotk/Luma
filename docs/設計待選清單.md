# 設計待選清單

使用者喜歡的做法：重要畫面不要直接做一版就上線，先產幾版並排比較（放
`design-history/`，一個功能一個資料夾每版一個檔，或五版並排在同一個
HTML），使用者挑完（或混搭）才改 App。這份是「還沒經過比較、之後要一個
一個請 Claude 設計」的清單，2026-10-02 使用者要求記下來、之後慢慢做。

做完一項就在後面標 ✅ 跟設計稿檔名，使用者挑完版本再標上選了哪版。

## 優先（常用、而且已經越長越擠）

1. **頻道詳情頁**：簡介、上傳頻率圖、全部影片 (N)、類型篩選、隱藏已看過
   兩排篩選、影片清單一路疊下來。可比：分頁式（簡介／影片分開）、圖表收合、
   篩選收進一顆按鈕。
2. **影片列**：縮圖、時長、左上已看過紅標、右上快取小點、往左滑兩顆按鈕，
   標記越來越多。可比：已看過／已隱藏／快取來的這幾種狀態怎麼表示才不雜。
3. **浮動播放器**：直接做出來沒給選過。可比：標題列樣式、收合後的小泡泡
   （圓形／膠囊／縮圖）、要不要停靠到邊緣。
4. **YT 分類頁上方工具列**：分類篩選、依頻道／依影片切換、排序、重新整理
   都擠在頂端。

## 其次（不常開，但一直加設定）

5. **設定頁**：設定項目一路往下排，可比分組卡片、分區標題等排法。
6. **冷藏區呈現方式**：目前是收合在最下面。可比：獨立分頁、跟垃圾桶放一起、
   只顯示一排頭像。

## 整個 App 共用（一次決定全部受惠）

7. **空狀態／載入中** ✅ 設計稿：`design-history/2026-10-02_空狀態與載入中五種風格.html`
   → **使用者選了第 5 版「先顯示舊的、背景更新」，已做進 App（2026-10-02）**
8. **確認對話框、底部提示訊息**：刪除確認、提示樣式各頁不一致。
9. **共用小元件**：按鈕、篩選標籤（chip）、開關、卡片、徽章這些到處用的
   小元件本身的樣式（使用者 2026-10-02：「小工具本身也可以讓我慢慢選」）。

11. **左側選單直接選英文／日文** ✅ 設計稿：
    `design-history/2026-10-02_選單語言學習捷徑五種風格.html`（等使用者挑）。
    使用者原構想：「語言學習」那一行右邊多兩個小標籤「英」「日」直接點，
    原本進去再用下拉選單切換的方式保留，多一個入口。

## 英文學習

10. **測驗頁、結果頁**：每天用，從沒比較稿；答對答錯的回饋、結果頁呈現方式。

## 已經比較過的（不用再做）

App 首頁、YT 頻道整體版面、雲端同步、除錯頁、日文月曆、左側選單、頻道長按
選單（`2026-10-02_頻道長按選單五種風格.html`，等使用者挑）、置頂樣式、音樂
功能，以及抽屜裡「敬請期待」的那些功能。
