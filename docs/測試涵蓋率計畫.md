# 測試涵蓋率計畫

2026-11-12 使用者：「每個功能邊界＋測試等等都補到 95%」「可以先規劃（寫上註解），然後開始一個一個補」。

## 標準（每個功能都一樣）

- 每個功能（`lib/features/<功能>` 加上它用到的 `domain`／`data` 檔案）**行涵蓋率 ≥ 95%**。
- 一定要有**邊界測試**：空值、0、負數、太長、沒填、按取消、找不到、重複、第一次沒有基準、
  亂寫的設定值或雲端資料、網路失敗。
- 流程要從頭點到存檔，不能只 pump 畫面。寫法參考 `test/features/ledger/ledger_flows_test.dart`：
  一顆按鈕觸發流程 → 走完表單 → 檢查存進去的資料。
- 改功能時一起補測試。量出來掉到 95% 以下就補回來。
