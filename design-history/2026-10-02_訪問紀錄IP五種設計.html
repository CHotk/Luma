訪問紀錄（誰打開了 Lume）：五種設計

目的：Lume 放在 GitHub Pages、網址是公開的，想確認真的只有你自己在用，看到陌生人打開過能馬上知道。每一版兩支手機：上面是一切正常（只有你），下面是出現陌生裝置時的樣子。

先講怎麼做得到（這部分五版都一樣）

GitHub Pages 只是放靜態檔案，不給看存取紀錄；網頁本身也拿不到自己的 IP。而陌生人的瀏覽器沒有你的 R2 金鑰，沒辦法把紀錄寫進你的 R2。所以要多一個小東西：
打開 Lume→ 送一個「我來了」Cloudflare Worker（免費）→ 記下R2 裡的訪問紀錄→ 你的 App 讀這個頁面
  1. Worker 跟你的 R2 在同一個 Cloudflare 帳號，免費額度一天 10 萬次，綽綽有餘。它看得到真正的 IP、國家／城市、電信商（Cloudflare 自動附的），App 只送「裝置代號＋瀏覽器型號」。
  2. 認裝置不認 IP：手機換基地台、開 VPN，IP 每天都會變，用 IP 判斷「是不是我」會一直誤報。所以每台裝置第一次打開時產生一組隨機代號存在本機，你在自己的裝置上按「這是我的」，之後那台不管 IP 怎麼換都算你；沒被認領的代號＝陌生裝置。IP 留著給你對照用。
  3. 紀錄只留 90 天，同一台裝置一小時內重複打開只記一次，免得紀錄爆量。
